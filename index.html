إعدادات التابلت للتشغيل دون إنترنت

  1. تنزيل حزمة اللغة العربية:

    اذهب إلى إعدادات التابلت (Android Settings) ← الإدارة العامة ← اللغة والإدخال ← الكتابة بالصوت من Google ← التعرف على الكلام دون اتصال (Offline Speech Recognition).

  2. تثبيت اللغة:

    اختر علامة التبويب "الكل" (All)، وابحث عن العربية (العربية) واضغط تحميل.

  3. تأمين إضاءة الشاشة:

    يستخدم التطبيق نظام Wake Lock لإبقاء شاشتك مضيئة. يرجى إبقاء التابلت متصلاً بالشاحن في المحراب للتأمين الكامل.

تحديث التطبيق لاحقاً عبر GitHub لن يمحو الصور المحملة أو حزمة الصوت الخاصة بالنظام.
